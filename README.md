# Thread-Safe Hotel Reservation Engine

A Core Java hotel reservation backend that supports Standard, Deluxe and Suite rooms
with room-specific pricing and discounts. The goal is a thread-safe booking process
that prevents double-booking.

## Progress
- [x] Module 1-2: Room model, inheritance, polymorphic pricing
- [ ] Module 3-4: Room registry (ConcurrentHashMap) and HotelService
- [ ] Module 5-6: Exceptions, validation, file persistence
- [ ] Module 7-8: Race condition demo and ReentrantLock
- [ ] Module 9-10: Testing and final README

## Tech
Core Java, OOP, Collections, multithreading
